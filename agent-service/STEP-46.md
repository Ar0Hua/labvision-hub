# Step 46：图片组分组与离群候选

## 本步完成

- 对应 FR-04 的分组和有依据的离群项分析，接入现有图片组相似度回答。
- 使用确定性的完全链接合并：组内每一对已知余弦分数均至少为 0.850。
- 分组按最高组间最低分数合并，同分按图片 ID 顺序决定，避免相似链误合并。
- 至少三张图片、候选与所有其余图片分数完整且最高值低于 0.300 时，输出离群候选。
- 每组提供图片 ID、组内最低相似度；离群候选提供最高分数及覆盖率。
- 拒绝不对称、越界、布尔值和非有限分数，缺失向量不能作为离群依据。
- 使用现有 Java 鉴权后图片集合，不新增外部数据访问。

## 验证与边界

- Python 全量 62 项测试通过，包含链式误分组、缺失证据、非法矩阵、回答集成。
- 阈值为尚未经过真实实验室数据校准的初始启发式，回答明确披露。
- 相似组不等同于重复图片；离群只描述向量差异，不代表实验异常。
