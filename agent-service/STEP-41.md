# Step 41：空间统计意图路由与证据回答

## 对应文档

- P0 / FR-05：空间统计问答必须优先调用确定性工具，不得由模型根据抽样图片估算。
- 阶段 5：统计回答携带范围、采集时间、总量和结构化分布证据。

## 本步完成

- Python 新增严格的 `SpaceStatistics` 契约，拒绝未知字段、负数、超长分布、不一致空间范围和无时区采集时间。
- 任务运行器识别空间容量、使用率、图片数量、分类/标签/大小分布及上传趋势问题，调用第 40 步的 Java 统计接口。
- 统计任务不再执行图片关键词召回或视觉分析，避免从样本图片推断全空间数值。
- 确定性回答展示当前空间、UTC 采集时间、图片总数、容量/数量上限与使用率、主要分类、常用标签、文件大小分布和最近上传趋势。
- 回答明确标注数值来自当前权限范围内的数据库统计，不是模型估算。
- SSE 记录 `space_statistics` 的开始与完成摘要，不在事件中暴露用户查询、令牌或无界统计明细。
- 路由触发词避免使用单独的“文件大小”，防止“找小于 1MB 的图片”被误判为空间统计。

## 边界

- 当前为可审计的确定性中文摘要，不使用 LLM 自由改写统计数值。
- 尚未实现多空间比较、重复率、无标签率、低质量率和长期未维护率；这些指标需先增加 Java 确定性查询。
- 尚未在空间分析前端页面增加快捷入口，本步只接通现有 Agent 对话任务。
- 本步不连接真实数据库、Redis 或 DashScope。
