# Step 44：权限图片组的 Qdrant 相似度矩阵底座

## 对应文档

- P0 / FR-04：对 2～20 张已选图片形成图像向量相似度证据。
- 阶段 5：相似度矩阵必须限定在当前任务空间和已授权图片集合内。

## 本步完成

- 新增 `PictureSimilarityMatrix` 类型，保持调用方给定的图片顺序并输出对称矩阵。
- 对每个已鉴权图片 ID 使用 Qdrant `image_dense` 向量查询，不依赖 DashScope 文本 embedding。
- 请求严格限制为 2～20 个唯一正 Long 图片 ID，仅接受 `public` 或合法 `space:<id>` 范围。
- 每次 Qdrant 查询同时绑定 `scopeKey`、未删除条件、选中图片 ID 白名单和当前图片排除条件。
- 公共图库范围继续附加审核通过条件。
- 丢弃白名单以外、非字符串或自引用的候选图片 ID，防止向量结果扩大 Java 已授权集合。
- 双向查询分数取平均形成对称值；对角线固定为 1，缺失向量证据保留为 `None`，不伪造相似度。
- 拒绝布尔值、非数值、非有限值及超出余弦范围 [-1, 1] 的 Qdrant 分数。

## 边界

- 调用该接口前仍必须由 Java 对整个图片组执行当前用户权限校验；Qdrant 不是授权事实源。
- 本步只提供可信矩阵底座，尚未接入最终回答、代表图、重复组、聚类或异常项计算。
- 本步没有连接真实 Qdrant、DashScope、COS 或生产数据库。
