# 第 24 步：跨服务任务取消传播

## 本步完成

- Java 内部任务上下文返回当前状态，Python 不再只依赖启动时的 PENDING 快照。
- 用户取消使用事务同时写入 `CANCELLED` 状态与持久事件，SSE 可立即恢复该终态。
- Python 在意图解析、关键词召回、向量召回、候选回源及答案落库前检查任务是否仍为 RUNNING。
- 发现取消后不再写 tool result、引用、答案、成功或失败状态，避免把用户取消覆盖为执行失败。
- 终态写入发生并发冲突或短期令牌到期时，失败处理不会再次抛出导致后台任务失控。

## 当前限制

正在进行中的单次 HTTP 模型请求不能被强制中断，但请求返回后、任何结果持久化之前会再次检查取消状态。
