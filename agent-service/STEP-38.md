## 本步完成

- `SearchIntent` 增加显式 `reset` 信号；千问接收本轮问题和上一轮已验证意图，输出合并后的完整类型化状态。
- LangGraph checkpoint 持久化当前结构化意图，仍使用 `userId:conversationId` 作为隔离键并沿用 TTL。
- 下一轮检索恢复格式、分类、标签、日期、尺寸、大小、排序等条件，新解析结果写回 checkpoint。
- “重置”“重新开始”“清空条件”等明确表达会清除旧条件；模型不可用时仍以确定性规则继承或重置。
- checkpoint 旧值先经 Pydantic 严格校验和归一化，未知字段、越界值或损坏状态不会注入模型。
- checkpoint 不保存空间授权凭据；每个新任务仍从 Java 签名上下文取得当前空间，并由 Java 重新做权限查询与候选复核。
- 视觉分析追加回答时保留本轮结构化状态，避免分析阶段意外丢失下一轮上下文。
