# 第 15 步：权限安全的 Java 图片关键词召回

## 本步完成

- 新增内部接口 `POST /api/agent/internal/tasks/{taskId}/pictures/search`。
- 搜索空间完全取自已签名且每次重新校验的任务上下文，请求体不能传入 userId 或 spaceId。
- 公共图库强制 `spaceId IS NULL` 且审核通过；空间会话强制使用会话绑定空间，并复用现有空间查看权限复核。
- 支持名称、简介、分类、标签关键词，以及分类/标签精确约束；单次最多返回 20 条。
- 只返回检索所需元数据和字符串 ID，不返回永久 COS URL、审核信息或原始数据库实体。
