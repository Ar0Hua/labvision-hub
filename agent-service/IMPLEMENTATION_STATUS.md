## 重要实现边界

- 匹配等级是初始排序信号，不是实验置信度；基础分数中的视觉/文本信号取自渠道排名，不伪称余弦相似度。真实权重与阈值尚待标注数据校准。
- 颜色为RGB每通道范围；Lab/CIEDE2000、cross-encoder和BM25属于P1。
- 全范围会话固定创建时授权快照；新增空间需新会话，快照中空间撤权后拒绝继续访问旧会话。全范围统计需明确具体空间，不把公共图统计冒充全范围。
- 日期排序仅作用于融合候选，不声称全库最新/最早排名。上传人按明确ID识别，不从姓名猜测ID。
- 当前checkpoint保障检索图节点恢复；已发布视觉结果持久保留，重试会重新分析视觉部分，不提供供应商token级断点续传。
- 输入和视觉token为保守预留；真实用量取供应商usage。费用限额默认关闭，启用前必须配置同币种真实单价；已产生的供应商费用无法撤销。
- OpenTelemetry当前输出本地脱敏JSON，Java为关联日志而非完整Java SDK span；远端collector、全栈自动埋点和告警需部署时接入。
- 已发出的短期图片URL在TTL内可能继续有效；已经交付客户端的数据无法被服务器追溯撤回。
- 20张是已确认MVP上限；不将正文提到的50张扩展能力计作已实现。
