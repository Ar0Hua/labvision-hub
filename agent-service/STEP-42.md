# Step 42：权限图片组的确定性元数据对比

## 对应文档

- P0 / FR-04：图片组共性与差异、分组、代表图及异常项必须给出判定依据。
- 阶段 5：图片组分析先使用结构化聚合，再逐步加入向量与 VLM 证据。

## 本步完成

- Python 新增 `PictureGroupAnalyzer`，支持对 2～20 张已授权图片执行确定性元数据聚合。
- 当用户选择至少两张平台图片并提出“对比、比较、共同点、差异、分组、代表图”等请求时，运行器进入 `picture_group_analysis` 分支。
- 分析前使用任务服务令牌调用 Java 图片详情接口，逐张重新校验会话范围、空间权限、删除状态和公共图库审核状态。
- 输出格式、分类、横/纵/方形方向、分辨率范围、文件大小范围和共同标签，并为所有参与图片生成真实 citation。
- 元数据代表项按字段完整度和可用分辨率确定，回答明确说明它不代表视觉质量或实验价值。
- 无法从元数据确定的视觉差异、相似度矩阵、重复组和异常项不会猜测，回答明确标注需要后续视觉/向量证据。
- SSE 记录图片组工具开始、完成数量及逐图引用；图片组请求不会误走关键词检索。

## 边界

- 当前前端任务契约最多携带 5 张平台示例图；分析器本身限制为 2～20 张，为后续扩展选中图片数量保留边界。
- 本步尚未读取 Qdrant 图像向量或 AI 特征表，因此不提供相似度分数、聚类、重复组或视觉异常判断。
- 本步不把元数据缺失直接解释为图片质量差，也不推断实验结果与科研结论。
- 本步未连接真实数据库、Qdrant 或 DashScope。
