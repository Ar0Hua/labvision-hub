# Step 59：显式多空间对比及历史权限校验

- 支持“比较空间 9、10 的图片数量”等请求，空间 ID 取自任务原始问题，不信任模型指定的范围；限制 2 至 5 个不同正整数 ID。
- Java 对全部空间预先鉴权，并在返回前再次鉴权；Python 输出对比表及各空间统计证据。
- 绑定空间的会话访问重新校验空间权限；对比任务的事件回放重新校验所有对比空间，撤权时不读取事件。
- 前端报告下载增加任务事件访问校验，避免绕过对比空间权限。
- Python 75 项测试、Java Agent 全量测试和前端 build-only 通过；新增撤权拒绝事件回放测试。
- 这不是跨全部授权空间的全局检索，也不自动从空间名称推断 ID。
- 未部署服务、未执行数据库迁移，真实 MySQL/云模型联调仍待进行。
