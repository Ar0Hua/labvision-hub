# Step 36：平台图片示例检索

## 对应文档

- P0 / FR-01：支持以平台内一张或多张视觉资产作为检索示例。
- 权限约束：示例图片和召回结果都必须由 Java 权限域校验。

## 本步完成

- 消息请求支持最多 5 个 `examplePictureIds`，任务表持久化本次示例，避免依赖易变的前端状态。
- Java 在任务创建前校验示例图片可见性，向 Python 传输时保持雪花 ID 字符串精度。
- Python 使用示例图片在 Qdrant 中已有的 `image_dense` 向量执行 ANN 检索，限定当前公共图库或团队空间，并排除示例本身。
- 图片召回候选回源 Java 二次鉴权，再与关键词、文本向量召回进行加权 RRF 融合。
- 文本向量与图片向量通道各自独立降级，任一外部调用失败不会阻断其他召回通道。
- Agent 工作台支持选择平台图片 ID；图片详情页增加“Agent 查相似”入口并自动带入当前图片和空间。

## 安全与一致性

- 客户端不能提交任意图片 URL，只能提交平台图片 ID。
- 空间范围由会话绑定，不信任客户端另行传入的过滤条件。
- Qdrant 只作为候选召回源，最终结果始终以 Java 权限校验为准。
