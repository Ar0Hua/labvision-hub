# Step 27 - DashScope 视觉分析适配器

本步把已授权的短期图片输入接入 DashScope OpenAI 兼容视觉接口。

- 仅当同时配置 API Key 与视觉模型时启用，默认不会产生外部模型调用。
- 单次默认最多 4 张、硬上限 8 张；输入必须是无内嵌凭据的 HTTPS 地址。
- 提示词要求区分元数据、可见观察和不确定推断，并逐条引用站内 pictureId。
- 模型失败时降级为确定性检索答案，既有候选与引用不丢失。
- 模型调用前后检查取消状态，避免取消后继续写入分析结果。

测试使用本地 MockTransport，不调用真实 DashScope，也不消耗模型额度。
