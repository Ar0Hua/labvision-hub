# Step 40：权限确定的空间统计内部工具

## 对应文档

- P0 / FR-05：优先调用确定性统计工具，结论携带范围、时间点和总量。
- 阶段 5：将现有空间分析接口包装为 Agent 只读工具。

## 本步完成

- DDD 后端新增 `AgentInternalSpaceAnalyzeService`，完整复用现有 `SpaceAnalyzeApplicationService` 的容量、分类、标签、大小和上传趋势统计。
- 新增 `GET /agent/internal/tasks/{taskId}/spaces/summary` 内部接口，只接受任务服务令牌。
- 用户和空间范围只从重新校验后的签名任务上下文获取，不接受 Agent 自行提交 `userId`、`spaceId`、全库范围或 SQL。
- 调用统计服务前重新加载当前用户；用户已删除或不存在时拒绝统计。
- 返回值包含范围类型与空间 ID、UTC 采集时间、容量/数量、分类、标签、文件大小分布和最近 24 个月上传趋势。
- 分类和标签分布限制为前 20 项，趋势限制为最近 24 个周期，避免把无界聚合结果送入模型。
- 公共图库范围仍沿用现有空间分析服务的管理员权限规则，内部接口不会绕过原有授权。

## 边界

- 本步只提供 Java 确定性统计工具与内部契约；下一步再接入 Python 意图路由和基于证据的自然语言回答。
- 无标签率、低质量率、重复率和长时间未维护率需要新增确定性统计查询，不在本步伪造或估算。
- 本步不连接真实数据库，也不修改数据库结构。
