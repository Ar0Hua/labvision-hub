# Step 69：模型用量与费用预算

- 所有任务内模型调用（意图、文本 embedding、视觉批次、跨批汇总）接入输入/视觉预留、输出上限、模型调用数及可配置费用预留检查。
- 单价通过 AGENT_MODEL_PRICES_JSON 配置，每个模型需 inputPerMillion/outputPerMillion，币种必须一致；正费用上限下缺失价格时拒绝调用。默认费用上限0表示未启用，不能宣称已限额计费。
- 单独记录供应商返回的实际输入、输出及可用视觉明细，失败/缺失 usage 不当作零费用；task tool_result 保存用量摘要。
- 输入估算采用 UTF-8 长度和可配置图片 token 预留；真实用量超限立即阻止后续调用，但无法撤回已产生费用，实际账单以供应商为准。
- Java 终态事件透传安全序列化的错误消息，使失败阶段能即时展示，并在同一事务锁任务后复核重试轮次。
- Python 100 项及 Java Agent 回归通过；未调用真实付费模型、未部署。索引 Worker 离线费用不属于单任务预算。
